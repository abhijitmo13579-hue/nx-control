NX Control is a tiny Windows tray app (about 95 KB) to control Nothing Headphone (1) from your PC.

## Features
- Noise control: High, Mid, Low, Adaptive, Transparency, Off
- Equalizer: Balanced, More bass, More treble, Voice, Custom
- Bass enhancement: Off, Level 1 to 5
- Low latency mode and Dual connection toggles
- Battery in the menu and on hover
- Start with Windows, global hotkeys (`Ctrl+Alt+Shift+N` / `Ctrl+Alt+Shift+L`)

## Install
1. Pair and connect the headphones in Windows Bluetooth settings.
2. Download `NXControl.exe` below and run it. It is not code-signed, so SmartScreen may warn: click **More info**, then **Run anyway**.
3. Click the headphone icon near the clock (it may be hidden under `^` at first).

This exe was built by GitHub Actions directly from the source code in this release.
